T-Block Origin is an MV3-based content blocker built on the uBlock Origin Lite engine.

The default ruleset corresponds to uBlock Origin's default filterset:

- uBlock Origin's built-in filter lists
- EasyList
- EasyPrivacy
- Peter Lowe’s Ad and tracking server list

You can enable more rulesets by visiting the options page -- click the _Cogs_ icon in the popup panel.

T-Block Origin is entirely declarative, meaning there is no need for a permanent background process for filtering to occur, and CSS/JS injection-based content filtering is performed reliably by the browser itself rather than by the extension. This means T-Block Origin itself does not consume CPU/memory resources while content blocking is ongoing -- its service worker process is required _only_ when you interact with the popup panel or the options pages.
